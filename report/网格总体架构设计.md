# 一、整体架构

整个系统：

```text
GameGridView (唯一 View)
│
├── GridLayoutEngine
├── VisibleRangeCalculator
├── ScrollController
├── FocusController
├── TextureCache
├── AsyncImageLoader
```

# 四、Grid 坐标系统

```cpp
int row = index / columns;
```

---

```cpp

    paddingLeft +
    col * (itemWidth + spacingX);

    paddingTop +
```

# 六、可见区域计算

# 已知：

```cpp
scrollY
viewportHeight
itemHeight
spacingY
```

---

# 行高：

```cpp
float rowHeight =
    itemHeight + spacingY;
```

---

# firstVisibleRow

```cpp
int firstRow =
    floor(scrollY / rowHeight);
```

---

# visibleRows

```cpp
int visibleRows =
    ceil(viewportHeight / rowHeight) + 1;
```

---

# lastRow

```cpp
int lastRow =
    firstRow + visibleRows;
```

---

# visible index range

```cpp
int startIndex =
    firstRow * columns;

int endIndex =
    (lastRow + 1) * columns;
```

限制：

```cpp
endIndex =
    min(endIndex, items.size());
```

# 八、Frame 流程

```cpp
void GameGridView::frame(FrameContext* ctx)
{
    updateInput(ctx);

    updateFocus();

    updateScrollPhysics(ctx);

    updateEnsureVisible();

    updateVisibleRange();

    textureCache.processUploadQueue();

    marqueeSystem.update(ctx->delta);

    animationSystem.update(ctx->delta);

    requestDraw();
}
```

# 十、自动滚动 ensureVisible

当焦点移动：

```text
自动滚动到可见区域
```

---

# item rect

```cpp
Rect rect =
    getItemRect(selectedIndex);
```

---

# 如果超出顶部

```cpp
if (rect.top < scrollY)
{
    targetScrollY = rect.top;
}
```

---

# 如果超出底部

```cpp
if (rect.bottom > scrollY + viewportHeight)
{
    targetScrollY =
        rect.bottom - viewportHeight;
}
```

# 十一、滚动系统

