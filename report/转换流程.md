# NDS Stub 滤镜 shader 转换流程

本文记录把 RetroArch `.glslp/.glsl` shader 转为 NDS Stub deko3d fragment shader 的当前流程。

## 目标渲染接口

NDS Stub 使用 ArcDelta Switch 前端的 `Gfx` 绘制矩形。顶点 shader 固定使用 `Default_vsh.glsl`，fragment shader 接收以下输入：

```glsl
layout (location = 0) in vec2 inUV;
layout (location = 1) in vec4 inColor;
layout (location = 2) in vec3 coolTransparency;
layout (binding = 0) uniform sampler2D inTexture;
layout (location = 0) out vec4 outColor;
```

转换后的滤镜只需要实现 fragment 阶段，并保持 alpha/coolTransparency 处理和默认 shader 一致。

## 通用转换步骤

1. 读取 `.glslp`，确认 pass 数量、shader 路径、filter/wrap 参数和默认参数。
2. 单 pass shader：提取 `#elif defined(FRAGMENT)` 到 `#endif` 之间的 fragment 逻辑。
3. 多 pass shader：第一阶段先做单 pass 原型，优先保留主要视觉效果；后续如需完整还原，再增加离屏 render target 和多 pass 绘制。
4. 替换 RetroArch 兼容层：
   - `Texture` -> `inTexture`
   - `TEX0.xy` / `vTexCoord` -> `inUV`
   - `TextureSize` / `InputSize` 可用 `vec2(textureSize(inTexture, 0))` 近似
   - `OutputSize` 暂不作为 uniform 传入，优先使用源纹理坐标或 `gl_FragCoord`
5. 删除 vertex 阶段、`MVPMatrix`、`VertexCoord`、`COLOR`、`TexCoord` 等 RetroArch 输入。
6. 参数先用 `.glslp` 或原 shader 的默认值写为 `const float`；后续如要 UI 可调，再新增 uniform/常量缓冲。
7. 输出时乘 `inColor.rgb`，alpha 使用：

```glsl
float alpha = texture(inTexture, inUV).a * inColor.a;
alpha *= clamp(sqrt(coolTransparency.x), coolTransparency.y, coolTransparency.z);
outColor = vec4(rgb, alpha);
```

## dot

来源：

- `build_windows/GBAStation/shaders/handheld/dot.glslp`
- `build_windows/GBAStation/shaders/handheld/shaders/dot.glsl`

原 preset 是单 pass。转换文件：

- `nds_stub/src/shaders/NdsDot_fsh.glsl`

处理方式：

- 保留原始 `gamma/shine/blend` 默认值。
- 原 vertex 阶段预计算的邻近采样坐标改为 fragment 内用 `textureSize(inTexture, 0)` 计算。
- 保留 3x3 邻域 dot bloom 混合逻辑。

## dot-clear

来源：

- `build_windows/GBAStation/shaders/shaders_glsl/phosphor-dot v3.3/Dot-clear.glslp`
- `passes/color-adjust.glsl`
- `passes/phosphor-dot.glsl`
- `passes/rgb-offset.glsl`

原 preset 是三 pass。当前转换文件：

- `nds_stub/src/shaders/NdsDotClear_fsh.glsl`

当前阶段处理方式：

- 做单 pass 近似原型。
- 保留 `phosphor-dot.glsl` 的点阵核心思路。
- 使用 `.glslp` 默认值：`DOT_GAMMA=2.2`、`DOT_SCALE_X=1.1`、`DOT_SCALE_Y=1.1`、`DOT_OPACITY=0.7`。
- `color-adjust` 和 `rgb-offset` 暂未完整还原；其中 gamma/视频空间转换做了轻量近似。

后续完整还原需要：

- 新增离屏 framebuffer/texture。
- 支持 pass0 -> pass1 -> pass2 的纹理链。
- 给 fragment shader 传入 `InputSize/TextureSize/OutputSize/OrigInputSize` 和参数 uniform。

## Stub 接入

当前新增接口：

- `Gfx::SetShaderMode(...)`
- `NdsGameLayer::setShaderEnabled(...)`
- `NdsGameLayer::setShaderType(...)`

当前支持：

- `dot` -> `NdsDot_fsh.dksh`
- `dot-clear` -> `NdsDotClear_fsh.dksh`
- `scanline` -> 占位，暂时使用默认 shader
- `crt` -> 占位，暂时使用默认 shader

NDS 屏幕绘制完成后会恢复默认 shader，避免遮罩、菜单和文字被滤镜影响。
